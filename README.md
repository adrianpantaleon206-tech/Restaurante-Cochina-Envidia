🍽️ Cochina Envidia — Restaurante & Bar
Página web responsive para mostrar el menú, los productos y la información de contacto de Cochina Envidia.
Banner del restaurante
✨ Características
•	Menú organizado por categorías.
•	Tarjetas con imágenes, descripciones y precios.
•	Botones para agregar productos.
•	Sección sobre el restaurante.
•	Información de contacto y ubicación.
•	Enlace directo a WhatsApp.
•	Diseño adaptable para computadora y celular.
🛠️ Tecnologías
•	HTML5
•	CSS3
•	JavaScript
•	Google Fonts
•	Font Awesome
📁 Estructura
cochina-envidia/
└── index.html

El HTML incluye el diseño CSS y la lógica JavaScript del proyecto.
🚀 Cómo ejecutarlo
1.	Descarga el archivo cochina-envidia-ordenado.html.
2.	Renómbralo como index.html.
3.	Ábrelo con Google Chrome, Firefox o Edge.
4.	Mantén conexión a Internet para cargar las imágenes, fuentes e iconos.
También puedes abrirlo con Live Server desde Visual Studio Code.

⚙️ Personalización
Puedes cambiar fácilmente:
•	Nombre del restaurante.
•	Productos y precios.
•	Imágenes.
•	Colores.
•	Número de WhatsApp.
•	Correo electrónico.
•	Dirección del local.
Ejemplo para cambiar una imagen:
<img src="imagenes/plato.jpg" alt="Descripción del plato">

📌 Nota
Las imágenes actuales se cargan desde Internet. Para publicar el proyecto, es recomendable guardar imágenes autorizadas dentro de una carpeta local llamada imagenes.
El carrito actual muestra una confirmación al agregar productos. Para convertirlo en un carrito completo, habría que añadir cantidades, total, eliminación de productos y envío del pedido.
